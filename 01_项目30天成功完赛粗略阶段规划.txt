【一】总体目标（完赛的定义）
--------------------------------------------------------------------------------

一句话目标：
  在 30 天内完成一套"能运行、能演示、能答辩"的桌面级原理样机，实现
  "振动感知 → PINNs 预测 → 阻尼调节 → 效果反馈"的完整在线闭环。

【1.1 五大必备成果（P0：缺一不可）】
  1. 振动信号采集 —— MPU6050 经 I²C(400kHz) 稳定输出 200Hz 振动加速度数据流，
     且 DLPF 带宽必须配置为 94Hz（DLPF_CFG=2）、量程 ±4g（详见 06 号文件第 5.1 节）；
  2. PINNs 预测模型验证 —— 模型训练收敛，含噪数据预测精度 R² > 0.90，
     并输出现测 vs 预测对比曲线；
  3. 树莓派部署 —— 模型导出 ONNX，在树莓派 4B 上完成在线推理，
     单次推理延迟 ≤ 30ms，控制周期 20ms 可稳定节拍运行；
  4. 步进电机阻尼调节 —— 28BYJ-48 + 丝杆驱动可变阻尼机构，可定量、
     可重复地改变等效阻尼（至少 5 档可分辨）；
  5. 闭环展示 —— 从传感器到执行器全链路自动运行，现场演示中
     "人为激励钢尺 → 系统自动加大阻尼 → 振幅明显下降"全过程可见。

【1.2 四项交付材料（P0：比赛报名/答辩硬性要求）】
  ① 项目 PPT（讲解 8~10 分钟版 + 答辩补充页）
  ② 演示视频（3 分钟，含闭环全过程与对照实验数据）
  ③ 技术文档包（方案说明、算法说明、实验记录、接口协议）
  ④ 答辩问答库（技术类 + 应用类 + 商业/转化类 共 ≥ 40 问）

【1.3 量化指标表（答辩时必须能报出数字）】
  ---------------------------------------------------------------------------
   指标                目标值              验证方式
  ---------------------------------------------------------------------------
   采样率              200 Hz             代码打印 + 时间戳统计 + 示波器旁证
   量程与带宽          ±4g / DLPF 94 Hz   寄存器读回值截图存证（见 06 号 2.4）

【1.3.1 最终 PPT 固定展示的"六个数字"（创新组评审口径，详见 06 号 4.4.1）】
  ① RMS 振幅衰减率 30%~60%（A/B/C 对照，n=3）
  ② 自由衰减阻尼比提升倍数 ζ₁/ζ₀ = 2~5 倍
  ③ 含机构端到端响应 <150 ms
  ④ 含噪预测 R²>0.90，主频误差<5%、幅值误差<15%、提前预警≥100 ms
  ⑤ 重复性：同工况 3 次 RMS 偏差 <15%
  ⑥ 连续运行 30 min ×3 次无致命故障
  ★ 这六个数互相印证、各自可追溯到原始文件——是回应"数据真实吗"的最强呈现。

【1.3.2 三层验证边界（对外表述纪律，PPT 第 2 页就写，详见 06 号 1.6）】
  · 仿真层：切深/转速/时滞/再生切削力全要素 → 证明 PINNs 学得会含时滞动力学；
  · 台架层：钢尺 + 外部激励 → 验证"感知—预测—半主动变阻尼"闭环能自动运行
    并抑制振幅增长（抑制机理与颤振一致）；
  · 机床层：尚未开展 → 明确路径（工业传感器 + 转速/切深接口 + 压电/磁流变）。
  ★ 禁止表述："我们复现了切削颤振"、"已可用于机床抑振"；
    正确表述："验证了颤振抑制的机理与闭环控制可行性"。

【1.4 明确不做的事（防范围蔓延，30 天做不完的坚决不做）】
  ✗ 不做真实数控机床切削实验（无设备、无时间，只做桌面级原理验证）
  ✗ 不做工业级压电/电磁主动控制（成本数千元，超预算）
  ✗ 不做变转速（SSV）抑振（需数控系统支持，且会改变切削参数）
  ✗ 不做无线传输、云端训练、APP、小程序（与核心创新点无关）
  ✗ 不做复杂 3D 打印异形结构（亚克力 + 螺丝能解决就不打印）

【3.3 关键风险与当天对策（本阶段高频坑）】
  · I²C 通信失败 → 先 `i2cdetect -y 1` 看地址（默认 0x68），查上拉电阻、

  · 传感器读数跳变 → 杜邦线接触不良（先测通断），再加 RC 低通
    （如 1kΩ + 100nF，截止约 1.6kHz）+ 软件 8 点滑动平均。

【四】第二阶段（D7~D13）：闭环打通期 —— 最小闭环能自动跑
--------------------------------------------------------------------------------

【阶段目标】
  打通"传感器 → 数据处理 → 算法预测 → 控制输出 → 执行器作动"全链路，
  即使预测精度还很差、抑振效果还很弱，也必须"自动跑起来"。

【4.1 数据流与接口（本阶段必须冻结的物理事实）】
  感知：MPU6050 ──I²C(400kHz)──> 树莓派        采样率 200Hz，单位 g 或 m/s²
        ★DLPF 带宽 94Hz（DLPF_CFG=2）、量程 ±4g、SMPLRT_DIV=4（见 06 号 2.4）
  预处理：8 点滑动平均 + 二阶巴特沃斯低通（截止 100Hz）+ 归一化
        ★RMS 双时间尺度（06 号 4.2 修正，替代原 0.5s 单窗口）：
             A_fast = RMS(最近 20ms)   快速检测，滞后小，用于每拍判定
             A_slow = RMS(最近 200ms)  趋势与阈值判断，更平稳
          （0.5s 窗口仅作历史趋势显示，不再作为控制判据——因为 fₙ≈20Hz、
            高 Q 系统的振幅包络时间常数只有 0.27~0.8s，0.5s 窗口滞后过大）
  推理： 滑动窗口特征 ──> PINNs（ONNX）──> 未来 N 步振幅/频率预测
  决策： 预测振幅 A_pred 与阈值 A_th 比较 → 计算阻尼增量 kd
         A_th = (2.0~3.0)·A_base（A_base 为开机稳定 2s 自动标定的基线 RMS）
         控制律（可解释、可复现，含工程细节）：
             e = max(0, A_pred − A_th) / A_th
             kd_raw = clamp(Kp · e, 0, 1)        Kp 初值 1.0，实验整定
             kd     = 速率限制 ±0.25/拍 + 迟滞（复位 0.6·A_th，防电机抖动）
  执行： kd → 电机档位 0~4 → 丝杆位移（M4/M5 细牙或 M6，导程 0.7~1mm）
         → 弹簧预紧力/摩擦片压力 → 等效阻尼↑（ζ 提升 2~5 倍）
  反馈： 持续监测 A_slow，若 2s 内衰减不足 20% 则 kd 递增加一级（上限 1.0）
  时间预算（06 号 4.3）：读 0.5~1ms + 滤波 2~5ms + 推理 10~30ms + 解算 <1ms
         + 电机动作 ~20ms + 机构阻尼生效 20~50ms ≈ 55~110ms（<150ms 目标）

【5.1 算法优化项（按性价比排序，做完一项再下一项）】
  P0-1  损失函数权重整定：数据项 + PDE 残差 + 初值/边界项三方权重扫描
        （建议做法：固定两项，扫第三项，记录 R² 或验证 loss 曲线）
  P0-2  傅里叶特征映射：对输入做多尺度频率编码，提升高频振动表征能力
  P0-3  训练策略：Adam 初收敛 → L-BFGS 精调（报告 2.3 节既定方案）
  P0-4  ★物理残差采用"加速度形式"（06 号 3.3）：残差 R(t) 只需一阶导数，
        避免二阶时间求导放大噪声；时滞项 x(t−T) 用延迟缓冲区/参数化处理；
        各项先无量纲化，防止梯度被大项支配
  P0-5  ★位移/速度重建：频域两次积分（除 iω）并高通去漂移，再用
        A = a_peak/ωₙ²（06 号 2.3）交叉校验，误差应在 ±20% 内
  P1-1  网络规模小幅扩展（5~8 层、64~128 神经元范围内试 2~3 组）
  P1-2  FFT 频谱辅助诊断：主频、频谱重心、频带能量占比作为对照特征
  P1-3  RMS 评价体系：A_fast(20ms)/A_slow(200ms)/峰值/峭度，统一评价脚本
  P1-4  ★精度报告口径：R² + RMSE + 主频误差(<5%) + 幅值误差(<15%)
        + 提前预警量(≥100ms)，五项一起报（只报 R² 不专业且易被追问）
  P2    轻量化：若推理延迟 > 30ms，做 INT8 量化/剪枝，或退化为 MLP 版本

【5.2 对照实验设计（答辩核心证据，必须严谨）】
  ---------------------------------------------------------------------------
   组别        条件                        记录内容
  ---------------------------------------------------------------------------
   空白组 A    不控制（阻尼固定最小档）      激励频率/幅值、RMS 时程、衰减时间
   对照组 B    固定阻尼（手动设为中档）     同上，用于证明"不是随便加阻尼都行"
   实验组 C    本系统闭环自动控制           同上 + kd 指令序列 + 响应延迟
   干扰组 D    C 组 + 传感器噪声/线缆晃动    验证鲁棒性（可选，时间够再做）
  ---------------------------------------------------------------------------
  ★ 每组必须同时记录四项指标（06 号 4.4，形成"指标矩阵"互相印证）：
      ① 振幅衰减率 η = (RMS_A − RMS_C)/RMS_A，目标 30%~60%
      ② 阻尼比提升倍数 ζ₁/ζ₀（自由衰减法：δ=ln(A₁/A₂)，ζ≈δ/2π），目标 2~5 倍
      ③ 响应时间（激励发生 → RMS 开始下降），目标 <150ms
      ④ 超调与稳态误差（kd 是否振荡、是否稳定停在新档位）
  ★ 自由衰减法测 ζ 的操作：轻拨钢尺使其自由衰减，取相邻两峰 A₁/A₂ 计算，
    控制前测 ζ₀、控制后测 ζ₁，与"衰减率"结果互相验证（不一致要查原因）。
  实验规范（写进实验记录模板）：
  · 每个工况重复 3 次；固定钢尺伸出长度、激励幅值、激励频率、采样时长；
  · 激励幅值必须 ≤ 2mm（防 ±4g 量程削顶；削顶数据一律作废重测，见 06 号 2.3）；
  · 同一天内完成同一组实验，避免温漂/装配变化引入误差；
  · 每组结束立即导出 CSV 原始数据（命名：日期_组别_工况_序号.csv）；
  · 计算衰减率 = (RMS_A − RMS_C) / RMS_A × 100%，同时报告 3 次均值与偏差。

【5.3 必须产出的图（PPT 直接可用，一图一行结论）】
  1. 感知层：MPU6050 原始时域波形 + 滤波前后频谱对比（说明数据可信）
  2. 算法层：观测 vs 预测曲线（标注 R²）+ 训练 loss 收敛曲线
  3. 决策层：振幅阈值线与 kd 指令时序图（说明控制逻辑可解释）
  4. 执行层：阻尼档位—RMS 标定曲线（说明执行有效且单调）
  5. 系统层：A/B/C 三组 RMS 对比柱状图或时程叠加图（核心结论图）
  6. 机制层：稳定性叶瓣图（MATLAB 零阶近似画出，说明颤振机理与工作点）
  ★ 强烈建议增加第 7 张（答辩杀手图）：自由衰减曲线对比 ——
    同一初始位移下"控制前 ζ₀"与"控制后 ζ₁"的包络对比，直接展示阻尼比提升。
  ★ 机制图补充（06 号 1.2）：再生颤振闭环示意（切屑厚度→切削力→振动→
    波纹→再生激励），一张自绘图讲清物理机制，评委非常吃这一套。
